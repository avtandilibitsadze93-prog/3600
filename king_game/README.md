# კინგი (King)

3 მოთამაშიანი, Widow-იანი (პრიკუპი) კარტების თამაშის სრული ონლაინ მულტიფლეიერ
აპლიკაცია — Flutter კლიენტი (Android + iOS) და Dart სერვერი.

## სტრუქტურა (მონორეპო, 3 პროექტი)

```
king_game_engine/   — თამაშის წესების ძრავა (pure Dart, Flutter-ის გარეშე).
                       ერთადერთი ადგილია სადაც წესებია დაწერილი — კლიენტიც
                       და სერვერიც ამავე კოდს იყენებენ პირდაპირ (path dependency).
king_game_server/   — ავტორიტეტული ონლაინ სერვერი (Dart, shelf + WebSocket):
                       მატჩმეიქინგი (საჯარო რიგი + პაროლიანი პრივატული
                       მაგიდები), ოთახები, დამალული ხელების უსაფრთხოება,
                       გათიშვისას ბოტის ჩანაცვლება, 4-საათიანი ბანი ვადამდელ
                       დატოვებაზე.
king_game/           — Flutter აპლიკაცია (ეს დირექტორია). სამი რეჟიმი:
                       "ონლაინ თამაში" (საჯარო მატჩმეიქინგი), "თამაში
                       მეგობრებთან" (პაროლით — 3-ივემ ერთი და იგივე პაროლი
                       რომ შეიყვანოთ, ერთ მაგიდაზე მოხვდებით) და "ერთი
                       ტელეფონით" (ლოკალური pass-and-play, დამოუკიდებელი
                       დეველოპმენტის/ტესტირების რეჟიმი).
```

## გაშვება დეველოპმენტისთვის

```bash
# სერვერი (ლოკალურად, ephemeral პორტზე ან 8080-ზე)
cd king_game_server && dart pub get && dart run bin/server.dart

# Flutter აპი
cd king_game && flutter pub get && flutter run
```

`king_game/lib/config.dart`-ში `defaultServerUrl` მიუთითეთ თქვენს სერვერზე
(იხილეთ იქვე კომენტარი `wss://`-ის აუცილებლობაზე რეალურ მოწყობილობებზე).

## ტესტები

სამივე პროექტს აქვს ავტომატური ტესტი, რომელიც რეალურ სცენარს უშვებს
(არა mock-ებს):

```bash
cd king_game_engine && dart test   # წესების ძრავა
cd king_game_server && dart test   # რეალური WebSocket კლიენტები სერვერზე
cd king_game && flutter test       # რეალური სერვერი + რეალური ეკრანები, 3 "ტელეფონი"
```

## ჩაშენებული წესები (`king_game_engine`)

- 32 კარტი (7→ტუზი), 3 მოთამაშე, თითო 10 კარტი + 2 Widow-ში
- ტუზის დარიგებით დგინდება ადგილი (ვისაც ბოლოს მოხვდა — ბოლოა)
- დეკლარაცია როტირდება მოთამაშეზე; 9 რაუნდში თითო მოთამაშე სულ 3-ჯერ
  აცხადებს (აქედან 1-ჯერ სავალდებულოდ კოზირი, მაქს. 2 ფიქსირებული)
- 6 ფიქსირებული კონტრაქტი მთელ თამაშში მხოლოდ ერთხელ ითამაშება თითოეული
- Widow-ის ჩატეხვის აკრძალვები (გული/დამა/ვალეტი — შესაბამის კონტრაქტში)
- გულის ჩამოსვლის შეზღუდვა (მეფე/გულის-არ-წაღება): პერსონალური —
  არ შეიძლება სანამ სხვა მასტი გაქვს ხელში; გატანა ყოველთვის თავისუფალია
- ქულები: მეფე -40, დამა/ვალეტი -10 თითოზე, არაფერი -4 თითო ხელზე,
  გული -5 თითოზე, ბოლო2 -20 თითოზე (-40 ორივეზე), კოზირი +8×აღებული ხელი
- **პრემია (+40):** თუ ვინც აცხადა (მხოლოდ თავად აცხადებელს ეხება) საკუთარ
  ნათქვამ უარყოფით რაუნდზე სუფთად გამოვა — არცერთი შესაბამისი ჯარიმის
  კარტი არ აიღო — ემატება +40

## ჯერ არ არის დასრულებული

1. **რეალურ სერვერზე განთავსება** — კოდი და `king_game_server/Dockerfile`
   მზადაა, მაგრამ არსად არ არის დეპლოირებული (საჭიროა Cloud Run/Fly.io/VPS
   ანგარიში).
2. **რეალური AdMob ID-ები** — ახლა Google-ის საჯარო სატესტო ID-ებია
   (`android/app/.../AndroidManifest.xml`, `ios/Runner/Info.plist`,
   `lib/services/ad_service.dart`).
3. **აპის აიქონი** — `assets/icon/app_icon.png` მხოლოდ დროებითი მაკეტია
   (მწვანე ფონი + "K" + მასტები). ჩანაცვლების შემდეგ გაუშვით:
   `dart run flutter_launcher_icons`
4. **ანგარიშების მუდმივი შენახვა** — სერვერზე ბანების სია ინახება JSON
   ფაილში (`ACCOUNTS_FILE`), რომელიც უნდა იყოს persistent volume-ზე
   ნამდვილ დეპლოიმენტში, თორემ დისკის განულებაზე ქრება.
